# Feedback 2.0.6.3

## Feature Wishes

1. Ich möchte zusätzlich zum Tutorial einen Onboarding Assistenten einbauen, der den Usern hilft einen ersten Bestand einzurichten. Im Moment muss man intuitiv verstehen, dass man zuerst auf "Neu" klicken muss und dann noch ein "Set aufnehmen" muss. Wenn wir wissen, dass der User sowas noch nie gemacht hat, dann solltn wir ihm dies durch einen Onboarding Assistenten erleichtern. Diesen Assistenten sollte man zusätzlich zum Tutorial sehen und nicht als Teil davon. Auch dieser sollte jederzeit wiederholbar sein.

2. Es soll über Sessions hinweg behalten werden was der User sieht. Also welche Gruppen er aufgeklappt hat und wo er im Dokument aktuell ist.

3. Wenn man ein "Backup" macht, soll dies auch nochmal in einem eigenen Dialog laufen und abgebrochen werden können. Hier sollte auch nochmal gefragt werden wie das Backup heißen soll. Der jetzige dafür vergebene Dateiname kann als Standard dabei vorgegeben sein.

4. Für das Bild der Karte, welches beim Hovern angezeigt werden kann, möchte ich eine eigene Spalte haben die man auch ausblenden kann. Statt Text "Bild" als Titel der Spalte können wir auch ein Bild Icon nehmen, aber dann in der Farbe des Titel Textes.

5. Als Standardname für einen Bestand soll immer "collection.csv" vorgeschlagen werden aber änderbar sein. Ich hatte beim Test einmal den Fall dass mir hier "bestand.csv" vorgeschlagen wurde.
